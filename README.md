 smart recipe recommendation system that suggests meals based on user preferences, dietary restrictions, and available ingredients. This project aims to simplify meal planning and promote healthier eating habits through intelligent filtering and ranking of recipes.

🚀 Features

🔍 Search recipes by ingredients

❤️ Personalized recommendations based on user preferences

🥗 Support for dietary restrictions (vegetarian, vegan, gluten-free, etc.)

📊 Nutritional info included (calories, protein, etc.)

🤖 AI-powered recipe suggestions using Google Gemini AI

📚 Learns from user feedback to improve future recommendations

📱 Responsive front-end UI built with React

🛠️ Technologies Used

Backend: C# (.NET Core Web API)

Frontend: React (JavaScript/TypeScript)

Database: SQL Server / Entity Framework

AI/ML: Google Gemini AI API
